#Financial Analysis Dashboard.

Project Overview
       This project is a Financial Analysis Dashboard developed using Microsoft Power BI to analyze Income, expenses, payment modes and financial transactions

     #  Tools Used:

       -Microsoft Power BI
       -Microsoft Excel
       -Power Query

      # features:

       -KPI Cards
       -Category-wise Analysis
       -Payment Mode Analysis
       -Treemap
       -Interactive Slicers
       -Transaction Table

#Files Included:
       -Financial Dashbord(.pbix)
       -Excel Dataset(.xlsx)
